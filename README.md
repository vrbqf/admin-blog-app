# Admin Panel - SSR Projekt

Jednoduchá administrace vytvořená v Node.js s využitím Expressu a Server-Side Renderingu (SSR).

## Jak spustit projekt

1. Ujisti se, že máš nainstalovaný Node.js.
2. V terminálu spusť server příkazem:
   ```bash
   node server.js

Otevři prohlížeč a jdi na adresu:
http://localhost:3000/admin
